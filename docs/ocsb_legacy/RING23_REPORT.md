## 3. 第三环：三种类无关提纯策略

指标：过滤后 B 精确率（10 类均值）、真桥梁 B_pos 保留率、仍有 B 的任务比例。

| 策略 | 精确率 | Δ | B_pos 保留 | 任务覆盖 |
|---|---:|---:|---:|---:|
| baseline | 0.332 | — | 100% | 100% |
| A τ_b=0.70 | 0.339 | +0.7 | 85.9% | 100% |
| A τ_b=0.80 | 0.345 | +1.3 | 68.6% | 100% |
| A τ_b=0.85 | 0.349 | +1.7 | 58.5% | 100% |
| B \|n_z\| ±0.20 | 0.345 | +1.3 | 47.0% | 99.7% |
| B \|n_z\| ±0.30 | 0.342 | +1.0 | 57.6% | 100% |
| B \|n_z\| ±0.45 | 0.337 | +0.5 | 70.1% | 100% |
| **C r ≤ 0.30 m** | **0.373** | **+4.1** | 21.8% | 100% |
| C r ≤ 0.50 m | 0.369 | +3.7 | 39.0% | 100% |
| **C r ≤ 0.80 m** | **0.363** | **+3.1** | **64.7%** | 100% |

### 策略定义

- **A（提高置信度）**：`q ≥ τ_b`，τ_b ∈ {0.7, 0.8, 0.85}
- **B（姿态一致性）**：以 B 集合自身的中位 `|n_z|` 为参照，剔除偏离超过阈值者
  （不依赖支持集坐标，因为缓存没有存支持集的 downsampled 坐标）
- **C（空间连通）**：每个 block 内以最高置信超点为核心，只保留 3D 距离 ≤ r 的 B

### 结论

**三种类无关策略都无法把 B 精确率显著提升**：

- 最好的 C（r≤0.8m）只有 **0.363（+3.1pp）**，代价是丢掉 35% 的真桥梁
- A 的极限（τ=0.85）是 0.349（+1.7pp），丢 41.5%
- B 基本无效（+0.5~1.3pp，丢 30–53%）

**精确率与保留率是单调权衡**，没有出现"提纯"的拐点。这与之前"第三环 0.391→0.514"的说法不符——那个结果不在本仓库，口径可能不同。

## 4. 对后续的判断

1. **B 的噪声不是几何能滤掉的**。`|n_z|`、`z_rel`、亮度在类内确实有区分（floor / counter / bathtub 最明显），但跨类的方向完全相反（curtain 竖直、floor 水平），任何固定阈值都会误伤。
2. **最根本的问题是 unannotated**：counter 38.6%、bed 30.5%、cabinet 25.7% 的 B 是未标注物体。这些物体在物理上与目标类共处同一家具系统（如台面上的电器），几何上无法区分。
3. **策略 C 是唯一有点效果的方向**（+3.1pp），说明"孤立的小红点"确实存在，但占比不高。

**建议**：如果第四环要继续，应当直接用 baseline 的 B（不滤），或者用 C r≤0.8m 的版本，在 10 类上分别看它对查询集的直接贡献——而不是继续追求 B 的纯度。因为 B 的纯度上限受限于 unannotated，而 unannotated 是 ScanNet 标注体系的问题，不是方法能解决的。
