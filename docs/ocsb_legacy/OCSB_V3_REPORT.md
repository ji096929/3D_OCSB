# 三层遗漏条件化选择性桥接（零训练版）

日期：2026-11-17
状态：**零训练基线里程碑**

---

## 0. 摘要

在冻结 COSeg 1w1s 的设定下，把"直接往原型池里塞无标签池 U"的负收益（−0.38pp）
扳成正收益（**+0.71pp Cumul**，bootstrap 95% CI [+0.02, +1.41]，P(Δ>0)=0.984）。

方法由三层组成，每一层对应一个具体的失败模式：

| 层 | 解决的问题 | 机制 |
|---|---|---|
| P1 提纯 | `p0>0.7` 的点精度只有 0.45，一半是背景 | 块内按 `R_s = sim_fg − sim_bg` 取 Top-40% |
| P2 单向 | U 会把 S 已认对的 TP 拉低（ΔTP = −6385） | `S + λ·relu(U − S)`，U 只能抬不能压 |
| P3 门控 | 易样本上引入 U 反而有害（Q5 −11.5pp） | `sim_fg_q < 0.65` 才开门，AUC 0.751 |

2 折交叉验证中，A 折和 B 折**独立选中同一个配置** `P3_l0.7@0.65`。

---

## 1. 口径说明

- 主指标：**Cumul**（先累加 10 个类的 TP/FP/FN，再算每类 IoU 取平均），
  与 COSeg 官方表格和 few-shot 分割文献一致（类间等权）。
- 显著性：**配对 bootstrap**（1000 次，按 episode 有放回重采样，同一索引同时算
  Baseline 和方法，取差值分布）。
- `Arith`（逐集 IoU 平均）仅作参考：本方法 +0.14pp，基本持平。
  原因是 Q1–Q3 的 +1.30 与 Q4–Q5 的 −1.55 在逐集平均下互相抵消。

## 3. 与 Oracle 上限的距离

| 口径 | Cumul | 说明 |
|---|---:|---|
| Baseline | 0.3229 | – |
| **P3（零训练，可用）** | **0.3299（+0.71）** | 只用无监督信号 |
| Naive-B | 0.3190（−0.38） | 直接加 U |
| Oracle-B（λ=0.9） | +4.34 | 真值挑桥梁 |
| Oracle-B+C（λ=0.9） | +4.90 | 真值挑全部前景 |

Oracle 与可用方法之间差 4.2pp，这个差距就是"用真值挑 B/C"与"用无监督信号挑"的差距。
前面已用四条独立路径验证过：在冻结特征上，这个差距无法靠任何现有信号填补
（浅层信号 AUC 0.625、完整管道反向 0.626、跨块独立考官 0.662、FPS/加权采样无差异）。

---

## 4. 局限

1. **Arith 口径基本持平**（+0.14pp）。Cumul 的提升来自 FP 大幅减少后的类间重新平衡，
   逐集等权下几乎消失。
2. **Q4/Q5 仍为负**（−1.50/−1.63），门控没有关严。
3. **Q3 的增益被门控误砍一半**（+2.69 → +1.35）。
4. **超参是手写的**：`keep_ratio=0.4`、`sim_fg_q<0.65`、`λ=0.7`，都是单变量硬阈值。

第 3、4 条指向同一个改进方向：**用训练替代手写规则**。

## 6. 下一步（Stage II 训练）

观察：P1 在 Q1–Q3 已达 +1.93，P3 因硬阈值降到 +1.30 且 Q4/Q5 仍有 −1.5。
如果用一个学出来的门控替代 `sim_fg_q < 0.65`，理论上可以同时拿到 P1 的难样本增益和
Q4/Q5 的零损伤。

训练原则：**不训 192×192 的类别特定 `W_phi`**（a2 阶段已验证会过拟合基础类），
而是训两个类别无关的相关性空间模块：

- `BridgeScorer`：10 维逐点统计 → 16 → 1，输出原型权重
- `OmissionGate`：8 维任务级 + 3 维点级 → 16 → 1，输出融合门控

详细设计见后续报告。
